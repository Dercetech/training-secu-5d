Referrer-Policy › Page bavarde

Cas 1 · Observation

Cette URL parle trop

Regardez la barre d’adresse : elle contient un faux reset_token. La réponse de cette page annonce Referrer-Policy: unsafe-url.

Ce qui devrait traverser la frontière

En suivant le lien, le navigateur peut joindre l’adresse complète de cette page dans le request header Referer, y compris sa query string.

Ouvrir le récepteur distant

À vérifier

  1. Dans Network, sélectionnez ce document et confirmez son response header Referrer-Policy: unsafe-url.
  2. Ouvrez le récepteur distant.
  3. Repérez reset_token=CLASSROOM-DEMO-4821 dans le header affiché.
