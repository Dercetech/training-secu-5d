Bonjour, utilisateur

Le navigateur lit actuellement le rôle inconnu dans un cookie JWT.

Exercice

Obtenir l’accès administrateur

  1. Ouvrez DevTools › Application ou Stockage › Cookies.
  2. Copiez la valeur du cookie secu5d_auth dans jwt.io.
  3. Dans le payload, remplacez "role": "student" par "role": "admin".
  4. Copiez le JWT modifié dans la valeur du cookie, puis rechargez la page /users.

Le cookie n’est volontairement pas HttpOnly. Aucun bouton ne modifie le token : manipulez directement le cookie dans DevTools.

Voir les utilisateurs

À corriger

Deux frontières, deux contrôles

Front-end

Ne plus faire confiance à un payload lu dans document.cookie. Utiliser un cookie HttpOnly et demander au serveur une session déjà validée avant d’afficher une zone restreinte.

Back-end

Vérifier la signature, l’algorithme et l’expiration avant de lire le rôle. L’API doit refuser le cookie modifié même si l’interface a été contournée.

Masquer l’interface améliore l’expérience ; protéger l’API impose réellement l’autorisation.
