03.02 · Configuration

Un secret reste sur le serveur

Observez une configuration qui code une fausse clé en dur et l’envoie au navigateur. Configurez ensuite le serveur avec CLASSROOM_SERVICE_TOKEN, sans jamais exposer sa valeur dans le JSON.

La route corrigée répondra 501 tant que vous ne l’aurez pas implémentée.

Le minimum

terminal : définit la variable
serveur  : lit la variable
navigateur : ne reçoit jamais le secret

Une variable d’environnement sépare la configuration du code versionné. Elle doit être définie dans le même terminal que celui qui lance le serveur.

La valeur utilisée dans ce laboratoire est fictive et locale.
