Quels scripts ont le droit de tourner ?

La page demande trois types de code : un fichier local, un composant hébergé sur Training et un script inline. La CSP décide lesquels peuvent s’exécuter.

Travail demandé

Autoriser précisément, sans ouvrir les vannes

  1. Dans Network, sélectionnez ce document et lisez son response header Content-Security-Policy.
  2. Dans la Console, repérez le refus concernant training.dercetech.com et celui concernant le script inline.
  3. Dans Flask ou Express, ajoutez uniquement https://training.dercetech.com à la directive script-src.
  4. Ne remplacez pas la liste par * et n’ajoutez pas 'unsafe-inline'.
  5. Redémarrez le serveur et rechargez sans cache : les cartes 01 et 02 fonctionnent, tandis que la carte 03 reste protégée.

Le bon aspect illustré

La CSP permet d’accorder une capacité à une origine connue sans accorder la même confiance à tous les scripts. Elle limite l’impact d’une injection, mais ne remplace ni l’échappement HTML, ni la validation, ni la suppression des usages dangereux de innerHTML.
