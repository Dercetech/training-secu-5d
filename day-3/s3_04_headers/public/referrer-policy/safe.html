Cas 2 · Exercice

Cette URL doit rester locale

Le faux token reste visible dans votre barre d’adresse. Votre travail consiste à empêcher sa transmission au prochain site en corrigeant le response header de cette route.

Objectif : aucun Referer

Dans Flask ou Express, trouvez la route /referrer-policy/safe/ et remplacez sa politique volontairement bavarde par no-referrer. Redémarrez le serveur et rechargez cette page avant de tester.

Ouvrir le récepteur distant

Résultat attendu après correction

  1. Network montre Referrer-Policy: no-referrer sur ce document.
  2. Le récepteur distant indique que le request header Referer est absent.
  3. Le faux token demeure dans l’adresse locale, mais ne franchit pas la navigation.
