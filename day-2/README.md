# Jour 2 — données, requêtes et validation

Le Jour 2 suit la progression présentée en classe :

```text
s1_01_intro     Découvrir SQL avec une base SQLite locale
s1_02_unsafe_search
                Première injection : modifier une recherche par e-mail
s1_03_fix_injection
                Lire une autre table, puis corriger la requête
s3_01_unsafe_register
                Découvrir une inscription JSON non validée
s3_02_validate_register
                Rechercher Pydantic ou express-validator, puis corriger
s3_03_complex_schema
                Écrire un schéma imbriqué avec tableaux, optionnels et null
s4_recap        Relier injection SQL, SHA-256 et contrôle d’accès
```

Chaque dossier suit la convention `s<section>_<numéro>_<mots-clés>`.
