S4 · Exercice récapitulatif

Reprendre le contrôle du serveur

Une recherche fragile, des mots de passe mal protégés et des commandes réservées à l’administrateur sont réunis dans une seule application fictive.

Connexion

Compte de départ : student / class101.

Services du serveur

Aucune session.

Résultats

Mission finale

Quatre preuves à obtenir

  1. Retrouvez les utilisateurs et leurs empreintes SHA-256 depuis la recherche de services.
  2. Écrivez puis utilisez votre propre script Python local, limité à quatre caractères de a-z A-Z 0-9, pour retrouver le mot de passe court de admin.
  3. Ouvrez une session en tant que admin avec le mot de passe retrouvé.
  4. Arrêtez tous les services avec les contrôles réservés à l’administrateur.

Application locale et données fictives. Travaillez uniquement dans ce laboratoire scolaire.
