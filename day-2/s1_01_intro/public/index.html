01 · Le geste

Interroger une base locale

Écrivez une requête SELECT, exécutez-la, puis observez les colonnes et les lignes renvoyées par SQLite.

Résultat

Exécutez une requête pour afficher les données.

Le minimum

Une table notes

SELECT *
FROM notes;

SELECT title, author
FROM notes
WHERE is_public = 1;

Colonnes disponibles

id
nombre
title
texte
body
texte
author
texte
is_public
0 ou 1

Cette première étape est une console SQL locale. L’injection sera étudiée ensuite, lorsqu’une application collera une saisie dans une requête qu’elle construit elle-même.
